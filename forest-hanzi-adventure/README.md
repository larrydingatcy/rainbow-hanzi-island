# 森林汉字探险队

这是一个独立开发的汉字认、读、写网页游戏，与工作区中的其他游戏没有代码或资源依赖。

## 玩法

孩子先选择小兔、狐狸、熊猫或小熊作为伙伴，然后依次经过五个森林树屋。每种玩法连续完成 3 个小挑战，共 15 题，约 15 分钟：

- 认一认：看图片选择汉字。
- 听一听：听普通话读音选择汉字。
- 读一读：先自己朗读，再听标准读音。
- 组一组：给大汉字选择一张合适的图片，答对后显示并朗读常用词。答题时不需要阅读句子。
- 写一写：在田字格中沿浅色字描写。

完成一轮后会出现两组同音字或形近字拓展。游戏没有分数、排名、倒计时或录音功能。答题反馈音效和普通话读音可以通过顶部按钮统一关闭。

每完成一个树屋的 3 个小挑战，所选动物伙伴会出现全屏欢呼动画，然后再进入下一个环节。

## 运行

这是无依赖静态网站。可以直接双击 `index.html` 在浏览器中打开，不需要安装依赖或启动本地服务器。
