# 彩虹汉字岛

一个为 5–6 岁儿童设计的中文识字复习网页游戏。无需账号、无需安装，适合在 iPad 上用手指或 Apple Pencil 游玩。

## 学习设计

每次“每日探险”只练 5 个字，约 5 分钟完成，并轮流覆盖五种记忆路径：

- **认一认**：根据图片找出汉字。
- **听一听**：听普通话读音后选择汉字。
- **读一读**：孩子先大声读，再点按钮听标准读音进行自我对照。
- **用一用**：在生活场景句子里选择合适的字词。
- **写一写**：沿浅色字用手指或 Apple Pencil 描写。

答错不会扣星；系统会记录每个字在五种练习中的熟练度，并优先再次安排练习较少的字。所有记录仅保存在当前浏览器的 `localStorage` 中。

## 字库

- 数字：一、二、三、四、五、六、七、八、九、十、百、千、万
- 颜色：红、白、蓝、绿、黄、橙、棕、紫
- 生活：嘴巴、鼻子、眼睛、耳朵、手、我、爸爸、朋友、家、妈妈、金鱼

字库集中保存在 `src/learning.js`，以后可以继续添加学校新学的字。

## 本地运行

这是一个无依赖的静态网站。用任意静态服务器打开项目目录即可，例如：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。通过 HTTPS 托管后，网站会缓存核心文件，可以从 iPad Safari 的分享菜单选择“添加到主屏幕”。

## 测试

```bash
npm test
npm run check
```

测试覆盖字库完整性、自适应选字、同类干扰项、分项进度、奖励规则、页面结构和离线缓存配置。

## GitHub Pages

仓库包含 `.github/workflows/pages.yml` 自动发布流程。首次发布前，在仓库 **Settings → Pages** 中把来源设为 **GitHub Actions**；之后每次推送 `main` 都会先运行测试，再更新网站。发布后把生成的 HTTPS 链接在 iPad Safari 中打开即可。
